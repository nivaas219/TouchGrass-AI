# 🌿 TouchGrass AI

**Take a break from your screen. Reconnect with the real world.**

TouchGrass AI is a simple, interactive web app that encourages users to step away from their screens and enjoy small outdoor activities. Choose your current mood and available time to discover outdoor missions, track your progress, and build healthier digital habits.

## ✨ Features

- 🌱 **Outdoor Missions** — Discover small, achievable activities to try outside.
- 😊 **Mood-Based Recommendations** — Choose your mood to find suitable missions.
- ⏱️ **Flexible Time Options** — Pick activities based on the time you have available.
- 📊 **Progress Tracking** — Track completed missions and your progress.
- 💾 **Local Storage** — Save your progress in your browser across visits.
- 🎨 **Responsive Interface** — Enjoy a clean, nature-inspired user experience.
- 🔄 **Reset Progress** — Start fresh whenever you want.

## 🎯 Why TouchGrass AI?

Spending too much time in front of a screen can make it easy to forget about the world outside. TouchGrass AI turns taking a break into a small, enjoyable challenge.

Instead of making big lifestyle changes, start with one simple mission: go for a walk, observe the sky, find five interesting things, or spend a little time with nature.

**Small steps. Fresh air. Better balance.**

## 🚀 Getting Started

### Prerequisites

Install the following on your computer:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nivaas219/TouchGrass-AI.git
   ```

2. Open the project directory:

   ```bash
   cd TouchGrass-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   ```text
   http://localhost:5173/
   ```

### Build for Production

Run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🧭 How to Use

1. Open TouchGrass AI in your browser.
2. Select your current mood.
3. Choose how much time you have.
4. Explore the suggested outdoor missions.
5. Complete a mission and update your progress.
6. Return whenever you need another screen break.

## 🔒 Privacy

Your mission progress is stored locally in your browser using Local Storage. The current version does not require an account to track progress.

Clearing your browser's site data may erase your saved progress.
